# Baraa Aesthetics

مشروع موقع عيادة براءة للتجميل غير الجراحي، مبني بـ React + Vite + Node/Express + MySQL.

## المتطلبات
- Node.js
- MySQL 8
- VS Code

## التشغيل

1. أنشئ قاعدة البيانات في MySQL:
```sql
CREATE DATABASE baraa_aesthetics CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. انسخ `.env.example` إلى `.env` وعدّل كلمة مرور MySQL إذا كانت موجودة.

3. ثبّت الحزم:
```bash
npm install
```

4. شغّل المشروع:
```bash
npm run dev
```

الموقع: http://localhost:5173
الخادم: http://localhost:8000
لوحة الإدارة: افتح `admin/index.html` من المشروع أو شغّلها عبر أي static server.

## حساب الإدارة الافتراضي
يتم إنشاء الحساب تلقائياً من:
ADMIN_USERNAME=admin
ADMIN_PASSWORD=ChangeMe123!

**غيّر كلمة المرور في `.env` قبل الاستخدام الحقيقي.**

## نظام الحجز
- السبت إلى الخميس مفتوح افتراضياً.
- الجمعة مغلق افتراضياً.
- 09:00 إلى 17:00.
- المواعيد ساعة تقريباً: 09:00، 10:00، ...، 16:00.
- الحجز يدخل Pending.
- الإدارة توافق أو ترفض.
- عند الموافقة يصبح الموعد Approved ومثبتاً.
- النظام يمنع تعارض المواعيد المعتمدة، كما يمنع إرسال طلب آخر لنفس الموعد أثناء وجود طلب pending.

## الصور
ضع صور العيادة المسموح باستخدامها داخل:
`public/images/gallery/`
وباقي مجلدات الصور موجودة لتوسعة المشروع.

## ملاحظة
قبل النشر العام يجب إعداد HTTPS، جلسات آمنة، أسرار قوية، والتحقق من المدخلات وحماية لوحة الإدارة بشكل مناسب.
